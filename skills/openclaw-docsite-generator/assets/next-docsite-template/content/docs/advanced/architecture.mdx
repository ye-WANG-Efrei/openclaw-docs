## System Flow

```text
User -> Agent -> Model -> Tools -> Skills -> Memory
```

This sequence matters because each layer has a different failure mode and a different optimization strategy.

## Component Breakdown

| Component | Responsibility | Inputs | Outputs | Typical failure mode |
| --- | --- | --- | --- | --- |
| User | Define intent and constraints | task, context, boundaries | request | ambiguous goal |
| Agent | Plan and orchestrate work | request, policy, skills | calls to models and tools | poor decomposition |
| Model | Reason, summarize, generate | prompt, retrieved context | text or structured output | capability mismatch |
| Tools | Act on files, services, or systems | explicit arguments | side effects, data | permission misuse |
| Skills | Provide procedural guidance | task patterns, references | workflow steering | stale or weak instructions |
| Memory | Preserve useful context | summaries, facts, state | later retrieval | noisy or unsafe persistence |

## Request Lifecycle

1. The user request arrives with explicit constraints.
2. The agent selects or inherits a model profile.
3. Relevant skills load to provide domain-specific procedure.
4. The model decides whether tool use is necessary.
5. Tool outputs are folded back into the reasoning path.
6. The system stores only the memory that will improve later work.

## Design Rules

- Keep model choice explicit enough to audit later.
- Treat tools as capabilities with permissions, not as neutral utilities.
- Make skills small, focused, and easy to review.
- Store memory only when the future reuse is worth the retention and security cost.

## Failure Modes To Watch

- The agent picks a high-cost model for trivial work.
- The skill is too vague, so the model re-invents the workflow.
- Tools expose actions that the prompt never justified.
- Memory keeps stale summaries that silently bias later runs.

## Review Checklist

- Can you identify where routing happens?
- Can you explain how skills are selected?
- Can you trace tool calls from logs or UI traces?
- Can you state what memory is persisted and why?
