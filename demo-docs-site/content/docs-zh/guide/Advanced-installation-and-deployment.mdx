# ClawBot 本地部署与飞书接入指南

> 项目名称为 `ClawBot`，当前 CLI 命令统一使用 `openclaw`。

## 1. 前置准备

本文档以 Windows + PowerShell 为主，默认你要完成的是：

- 在本机安装并运行 ClawBot
- 接入飞书机器人
- 通过 Cloudflare Tunnel 暴露公网 webhook

建议提前准备：

- [Git Bash](https://git-scm.com/install/windows)
- [Node.js](https://nodejs.org/zh-cn/download)
- [Docker](https://www.docker.com/)（如果你的后续能力或插件依赖它）
- 可托管到 Cloudflare 的域名

如果 `winget` 相关命令不可用，先安装或更新 [App Installer](https://apps.microsoft.com/store/detail/app-installer/9NBLGGH4NNS1)。

## 2. 安装 ClawBot

在 PowerShell 中执行：

```powershell
iwr -useb https://molt.bot/install.ps1 | iex
```

如果安装过程报错，优先按下面顺序排查：

1. 使用管理员权限运行 PowerShell
2. 确认 Git 已安装
3. 重启 PowerShell 后重试
4. 仅当前会话放开脚本执行权限

```powershell
Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
```

安装 Git 的常用命令：

```powershell
winget install --id Git.Git -e --source winget
```

安装完成后，可以先用下面的命令确认全局安装情况：

```powershell
npm list -g --depth=0
```

如果你在旧资料或旧截图里看到 `clawbot` 或 `clawdbot`，请统一替换为 `openclaw`。

## 3. 创建并配置飞书应用

飞书开放平台地址：

[https://open.feishu.cn/app?lang=zh-CN](https://open.feishu.cn/app?lang=zh-CN)

### 3.1 创建应用

1. 点击“创建企业自建应用”
2. 填写应用名称和描述
3. 点击创建

### 3.2 添加机器人能力

在左侧导航中打开“添加应用能力”，添加“机器人”能力。

### 3.3 配置权限

在“权限管理”中搜索并开通以下权限：

- `im:message`
- `im:message.p2p_msg`
- `im:message.group_at_msg`
- `im:message.group_msg`
- `im:chat`

建议直接搜索“消息”或“群组”来快速定位。

### 3.4 记录凭证

在“凭证与基础信息”页面记录以下内容：

- `App ID`
- `App Secret`

### 3.5 首次发布版本

在页面顶部点击“创建版本”：

- 版本号：`1.0.0`
- 更新说明：`初始版本`

## 4. 安装并配置 Feishu 插件

安装插件：

```powershell
openclaw plugins install @miheng-clawd/feishu
```

如果命令不存在，先执行 `npm list -g --depth=0` 确认当前实际安装出来的 CLI 名称；当前文档统一按 `openclaw` 处理。

写入飞书凭证：

```powershell
openclaw config set channels.feishu.appid "<YOUR_APP_ID>"
openclaw config set channels.feishu.appSecret "<YOUR_APP_SECRET>"
```

需要显式添加 channel 时，可执行：

```powershell
openclaw channels capabilities
openclaw channels add --channel feishu
openclaw channels list
```

成功后，你应该能在 `openclaw channels list` 中看到 Feishu 相关条目。

## 5. 启动 Gateway 并检查本地状态

先尝试直接启动：

```powershell
openclaw gateway restart
openclaw gateway status
```

如果 gateway 没有正常拉起，再切到本地模式：

```powershell
openclaw config set gateway.mode "local"
openclaw gateway restart
openclaw gateway status
```

常见判断方式：

- 如果状态中出现 `Gateway: bind=loopback (127.0.0.1)`，说明当前仍是本地监听
- 这时 ClawBot 本地可用，但飞书还不能直接从公网回调，需要继续配置 Cloudflare Tunnel

Feishu 默认 webhook 路径通常为：

```text
/feishu/events
```

因此本地回调地址通常是：

```text
http://127.0.0.1:3000/feishu/events
```

## 6. 使用 Cloudflare Tunnel 暴露 webhook

### 6.1 安装 cloudflared

```powershell
winget install Cloudflare.cloudflared
cloudflared --version
```

### 6.2 登录 Cloudflare

```powershell
cloudflared tunnel login
```

如果你的域名还没有托管到 Cloudflare，需要先把域名的 NS 切到 Cloudflare 分配的 nameserver。

### 6.3 创建 tunnel

```powershell
cloudflared tunnel create openclaw
```

这个命令会生成类似下面的内容：

- `cert.pem`
- `Tunnel ID`
- `credentials JSON`

### 6.4 绑定子域名

把 `<YOUR_DOMAIN>` 替换成你自己的完整子域名，例如 `openclaw.example.com`：

```powershell
cloudflared tunnel route dns openclaw <YOUR_DOMAIN>
```

### 6.5 编写 cloudflared 配置

创建或编辑：

```text
C:\Users\<YOUR_USERNAME>\.cloudflared\config.yml
```

填写：

```yaml
tunnel: openclaw
credentials-file: C:\Users\<YOUR_USERNAME>\.cloudflared\<TUNNEL_ID>.json

ingress:
  - hostname: <YOUR_DOMAIN>
    service: http://127.0.0.1:3000
  - service: http_status:404
```

说明：

- `service` 指向本地 Feishu webhook 服务端口 `3000`
- 最终飞书事件路径通常仍然是 `/feishu/events`
- 因此最终公网回调地址通常是 `https://<YOUR_DOMAIN>/feishu/events`

### 6.6 启动 tunnel

```powershell
cloudflared tunnel run openclaw
```

### 6.7 验证链路

先检查本地 3000 端口：

```powershell
Test-NetConnection 127.0.0.1 -Port 3000
```

期待看到：

```text
TcpTestSucceeded : True
```

再检查公网地址：

```powershell
curl https://<YOUR_DOMAIN>/feishu/events
```

如果配置正确，通常会返回可用的 HTTP 状态码，例如 `200`。

## 7. 在飞书后台配置事件订阅

如果你走的是 webhook 方案，在飞书后台选择“开发者服务器”。

填入公网回调地址：

```text
https://<YOUR_DOMAIN>/feishu/events
```

然后至少添加以下事件：

- `im.message.receive_v1`

最后保存并再次“创建版本”发布。

## 8. 端口与运行说明

当前文档中的端口分工如下：

- `18789`: ClawBot gateway，主要给 ws 使用
- `18791`: browser control
- `3000`: Feishu webhook
- Cloudflare Tunnel 转发到 `3000`

## 9. 模型与 Agent 路由示例

```json
{
  "agents": {
    "defaults": {
      "model": {
        "primary": "openrouter/anthropic/claude-3.7-sonnet"
      },
      "workspace": "C:\\Users\\<YOUR_USERNAME>\\.openclaw\\workspace"
    },
    "coder": {
      "model": {
        "primary": "openrouter/openai/gpt-4o-mini"
      }
    },
    "research": {
      "model": {
        "primary": "openrouter/anthropic/claude-3.7-sonnet"
      }
    }
  }
}
```

在飞书中可以通过不同 agent 使用不同模型：

```text
@coder 写一个 Python 爬虫
@research 帮我查一下 NVIDIA 财报
```

不指定时，默认走 `defaults`。

## 10. 建议把 API Key 放到环境变量

```powershell
[System.Environment]::SetEnvironmentVariable("OPENROUTER_API_KEY", "<YOUR_KEY>", "User")
```

## 11. 私聊机器人首次授权

如果 Feishu 私聊里提示未配置访问权限，先完成一次配对授权。机器人通常会返回类似信息：

```text
OpenClaw: access not configured.
Your Feishu user id: ou_**********4ca8
Pairing code: G******A
Ask the bot owner to approve with:
openclaw pairing approve feishu G*****A
```

在运行 ClawBot 的那台机器上执行：

```powershell
openclaw pairing approve feishu <PAIRING_CODE>
```
